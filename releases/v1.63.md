## PingPong v1.63

**Ping-pong role is now automatic**
- Each PC's role follows **N1MM**: **Run = RUN**, **S&P = INB**. It changes the moment the operator switches mode in N1MM, and all lamps learn it at once. Nothing to set.
- Every PC is switched to **Auto** once by this update, also PCs that had a fixed role.
- For special cases, **Options ▾ → Ping-pong role** still offers *always RUN*, *always INB* or *off*, e.g. an inband station that also calls CQ in Run mode. The menu shows the current automatic role.
- The lock rule is unchanged. After RUN transmits, the first INB that transmits takes the slot, and every other INB on that band is locked until RUN transmits again (or at most 40 s).
