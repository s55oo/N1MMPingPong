## v1.103 – shared radio: the message is found more reliably

On a shared radio the lamp sometimes showed RUN2 (the PC that only saw the radio transmit) without a message, because the real keying PC's caption came in a different packet than its TX flag.

- A PC's message caption now counts for 1.5 s, also when it arrives **before** or **after** the packet with the TX flag. The PC that sent the message takes the transmission over from the one that only echoed it.
- An old caption (from an earlier transmission) can't take it over later.
- 2 new tests.

Update the lamps **and** the Overview: Overview → **Update all lamps…**, then restart the Overview.
