### Change in v1.29 – everything in English
All texts in the lamp and in the watcher (`n1mm_watch.py`) are now in English, e.g.:

| Before | Now |
|---|---|
| `OO840G3 oddaja` | `OO840G3 transmitting` |
| `14 CW Run (ti)` | `14 CW Run (me)` |
| `F12 klic VKLOP – F12 = izklop` | `F12 call ON – F12 = off` |
| `… kliče (F12) · klik = utišaj` | `… calls (F12) · click = silence` |
| `BLOKIRANO · F1` | `BLOCKED · F1` |
| `F-tipke blokirane še 35 s` / `blokada potekla` | `F-keys blocked 35 s more` / `block expired` |
| `barva … je zasedena` | `color … is taken` |
| `N1MM ne pride sem` / `ni N1MM` | `N1MM not reaching here` / `no N1MM` |
| `čakam na N1MM…` | `waiting for N1MM…` |

### Updating
- **From v1.6 or newer:** start the lamp (or **Options ▾ → Check for updates**).
- **From v1.5:** download `n1mm_lamps.exe` below and replace the old one.
