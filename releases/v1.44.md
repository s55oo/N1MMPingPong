### Change in v1.44 – F12 call ends after the block time
- When the **F12 block time** is over, the **whole call ends**: blinking, border and F-key block stop on all receiving PCs, and the calling PC's call switches itself off. A new F12 starts a fresh call.
- The F12 block time is now **1–30 s** (default **30 s**), still set on the master only (**Options ▾ → F12 block time…**). Larger values saved earlier are capped at 30 s.

### Updating
- **From v1.6 or newer:** start the lamp (or **Options ▾ → Check for updates**). Update all PCs.
- **From v1.5 or older:** download `n1mm_lamps.exe` below and replace the old one once.
