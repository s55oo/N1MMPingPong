## v1.109 – second diagnostics: N1MM's packets next to what PingPong did

With **Options ▾ → Diagnostics (log to file)** on, `pingpong_test.log` now has, below each raw N1MM `RadioInfo` line, a `PP` line with PingPong's decision:

```
12:04:31.120  PP  RUN2 radio1  N1MM tx=True key=''  ->  PingPong tx=False key=''  [-]  <- ECHO ignored (another PC transmits on this band, no caption here)
12:04:31.310  PP  RUN3 radio1  N1MM tx=True key='F4 S51CAB'  ->  PingPong tx=True key='S51CAB'  [START]
12:04:31.400  PP  LAMP shows: who='RUN3'  text='S51CAB'  color=red
```

- `N1MM tx/key` = what N1MM sent, `PingPong tx/key` = what the lamp used; `[START]`/`[END]` = a transmission begins/ends.
- `<- ECHO ignored` and `<- caption carried over` say which echo-filter rule acted.
- `LAMP shows` is written whenever the lamp's display (who, message, colour) changes.

No change in behaviour; only the log is richer. Turn Diagnostics on on both PCs, transmit, and send the logs.
