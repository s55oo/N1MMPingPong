## PingPong v1.91

**Security: network password, safe spreadsheet exports**

### Network password (optional)
- New: **Options ▾ → Network password…** on the lamp and **Setup ▾ → Network password…** in the Overview (on the master PC the Overview also takes the lamp's setting). Use the **same password on every PC**.
- Every lamp message (hello, relay, command, ping answer) is then signed with **HMAC-SHA256** and a time stamp. Messages without it, with another password, changed on the way or older than 5 minutes (a recorded command played back) are ignored – nobody else on the LAN or ZeroTier can fake F12 calls, switch the lock or stop the lamps.
- The lamp says, in red, what it ignores: `… different network password – ignored`, `… no network password – ignored`, `… wrong time (check the PC clock) – ignored`. PC clocks must agree within 5 minutes.
- Only a key derived from the password is stored, never the password.
- Off by default: without a password everything works as before. With a password, all lamps must be v1.91.

### Spreadsheet exports
- The event log and **Save CSV…** write station names and details that start with `= + - @` with a leading `'`, so Excel never runs them as a formula.

Update: **Update all lamps…**, then **Update Overview to v1.91…** in the Overview. Then, if wanted, set the network password on every PC and in the Overview.
