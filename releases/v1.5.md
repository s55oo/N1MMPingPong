**PingPong** shows which computer/station on your network is currently **transmitting**. It listens to the N1MM Logger+ external UDP broadcast (XML) on port **12060** and lights up a small always-on-top window in that station's color, showing the caption of the pressed function key.

### Download
- **`n1mm_lamps.exe`** – standalone lamp, no Python required. Double-click to run. Put the optional `lamps.cfg` next to it.

### New in v1.5 – network discovery
- **All network adapters detected reliably** – wired LAN, Wi-Fi and VPN addresses are read directly from Windows, so the lamp always recognises its own N1MM station, even with Ethernet and Wi-Fi active at the same time. Network changes are picked up while running.
- **PingPong PCs find each other** – every lamp sends a small hello every 3 s on UDP port **12070** (separate from N1MM's 12060). A PC running PingPong whose N1MM traffic doesn't reach you is shown in the footer:
  - `RUN2: N1MM ne pride sem` – N1MM runs there, but its broadcast doesn't arrive here (check that PC's Broadcast Address)
  - `RUN2: ni N1MM` – PingPong runs there, but N1MM isn't broadcasting
- New options `--discovery-port` and `--no-discovery`.
- `build_exe.bat` for a one-click local build.

> Update **all** PCs to v1.5 – discovery works only between v1.5 lamps. If Windows Firewall asks on first start, allow **private networks**.

See the [README](https://github.com/s55oo/N1MMPingPong/blob/main/README.md) for N1MM setup and full usage.
