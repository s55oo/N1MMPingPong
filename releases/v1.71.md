## PingPong v1.71

**Overview: Emergency ▾ (for emergencies only)**
- **Restart all lamps…:** every lamp closes and starts again, with a few seconds without lamps. Use it if lamps hang or behave wrongly.
- **Stop all lamps…:** every lamp is **closed**. There are no lamps, no F12 calls and no ping-pong lock until each lamp is started again by hand on its PC.
- Both ask twice: first **Yes / No**, then you must **type `YES`** and press **Enter**. Anything else cancels, and nothing is sent.
- Accepted only from the master PC, by lamps v1.71 and newer.

Update first: **Update all lamps…** in the Overview; the Overview updates itself.
