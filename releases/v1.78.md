## PingPong v1.78

**Start the Overview from the master's lamp**

- New: **Options ▾ → Open PingPong Overview…** on the lamp. Only the **master's** lamp can use it; on the other PCs it is greyed out and names the master.
- The lamp starts `pingpong_overview.exe` from its own folder. If it is not there, the lamp offers to download it from GitHub (size and SHA-256 checked), saves it next to `n1mm_lamps.exe` and starts it.
- Only one Overview runs per PC; starting it a second time just says it is already running.

Update: **Update all lamps…** in the Overview (then close the Overview and open it from the master's lamp next time).
