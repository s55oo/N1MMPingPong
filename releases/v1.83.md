## PingPong v1.83

**QR code for the phone lamp**

- New: **Options ▾ → Phone lamp QR code…** opens a window with a QR code for each address of this lamp's phone page – the LAN address and, if the PC is on ZeroTier, the ZeroTier address. Scan it with the phone's camera and the phone lamp opens, no typing.
- The menu item shows the address(es) too; it is greyed out when the phone lamp is off or its port is busy.
- The QR code is made by PingPong itself (no extra library in the exe).

Update: **Update all lamps…** in the Overview.
