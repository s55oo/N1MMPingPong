### New in v1.26 – any color, readable text
- **Options ▾ → My color… → More colors…** opens the Windows color picker, so each PC can use any color, not only the 10 palette colors. A color too similar to one another PC has already chosen is refused, so stations stay easy to tell apart.
- **Text adapts to the color:** black text on light colors (gold, orange, light blue, light green, cyan, pink…), white on dark ones. Also on the color buttons in the *My color* dialog.

### Updating
- **From v1.6 or newer:** start the lamp (or **Options ▾ → Check for updates**).
- **From v1.5:** download `n1mm_lamps.exe` below and replace the old one.
