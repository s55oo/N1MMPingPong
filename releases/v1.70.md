## PingPong v1.70

**Ping-pong release time: set on the master**
- New on the master: **Options ▾ → Ping-pong release time…**, **0–40 s** (default 40 s). It sets how long an inband station stays locked if RUN doesn't transmit again.
- **0 = never by time.** The slot is freed only when RUN transmits, and the locked lamp shows `WAIT · INB1` without a countdown.
- The value reaches all lamps at once. Other PCs show it greyed out in their Options.
- The Overview shows it in the top line, e.g. `ping-pong lock: ON (release 20 s)`.
- A new master keeps the current value.

Update: **Update all lamps…** in the Overview; the Overview updates itself.
