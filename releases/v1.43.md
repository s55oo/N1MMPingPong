### New in v1.43 – F12 block time, set on the master
**Options ▾ → F12 block time…** sets how long an F12 call blocks F1–F11 on the other PCs (5–600 s, default 40 s).

- **Only on the master** – like the colors, the value goes to all lamps at once.
- On the other PCs the menu shows it greyed out, e.g. `F12 block time: 25 s (set on master RUN1)`.
- When the master changes, the new master keeps the current value.

The ping-pong lock's safety release stays at 40 s.

### Updating
- **From v1.6 or newer:** start the lamp (or **Options ▾ → Check for updates**). Update all PCs.
- **From v1.5 or older:** download `n1mm_lamps.exe` below and replace the old one once.
