### New in v1.10
- **Test mode log:** while **Options ▾ → Test mode** is on, every packet from this PC's N1MM is written to `pingpong_test.log` next to the exe (time, key caption, transmit state, frequency, mode). Use it to check exactly what N1MM sends for each function key.
- **Updater fix:** if the lamp was started from a kept backup (e.g. `n1mm_lamps.v1.6.exe`), an update now goes into `n1mm_lamps.exe` instead of creating names like `n1mm_lamps.v1.6.v1.6.exe`.

### Updating
- **From v1.6 or newer:** start the lamp and answer **Yes**, or **Options ▾ → Check for updates**.
- **From v1.5:** download `n1mm_lamps.exe` below and replace the old one.
