## CQ WW band status built into PingPong

The master lamp reads the active N1MM Logger+ log and sends RUN/MULT countdowns or TX1/TX2 band-change counts to all lamps. Only the normal PingPong executable is needed on each logging PC.

Enable **Application Info** in N1MM's Broadcast Data settings and add `127.0.0.1:12062` on that line. Open or reselect the contest after starting PingPong. Use **Options → Display → Show time since my last CQ WW QSO** for the optional local activity row.
