## PingPong v1.98

**Tidier menus**

### Lamp: Options ▾
About 30 items in one long list are now a short top level and five groups – nothing was removed:

- top line: **who and what this lamp is** – name, role (or MASTER), UDP port, version;
- **My name…**, **My color…**;
- **Display ▸** – compact mode, lamp size, night mode;
- **Calls and keys ▸** – F12 call on (also Shift/Ctrl+F2/F4), block my F-keys, sound;
- **Ping-pong and F12 times ▸** – on the master: ping-pong lock, release time, F12 call times (for all PCs); on the other PCs the master's values (greyed) and my role;
- **Phone lamp QR code…**, **Open PingPong Overview…** (master only);
- **Network ▸** – share my N1MM, Windows Firewall, network password (the group name warns `⚠ firewall` when the rule is missing, and shows `password ON`);
- **Updates ▸** – check now, switch version, revert, check at startup, install automatically;
- **Diagnostics (log to file)**.

### Overview
- **Setup ▾**, the **Allow web page in firewall…** button and the **Always on top** box are now one **Settings ▾** menu: save / restore setup, network password, web page in Windows Firewall (shows "allowed ✔" once the rule exists), always on top. The second button row is now just **Update all lamps…**, **Settings ▾**, **Statistics ▾**.
- If the web page isn't allowed in the firewall yet, the bottom line says so.

All help texts and the docs use the new menu paths.
