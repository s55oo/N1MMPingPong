### New in v1.23 – PingPong icon
The exe, the lamp's title bar and the taskbar now show the PingPong icon: two glowing station lamps (red and gold) with a ping-pong ball bouncing between them.

### Updating
- **From v1.6 or newer:** start the lamp (or **Options ▾ → Check for updates**).
- **From v1.5:** download `n1mm_lamps.exe` below and replace the old one.

Windows may keep showing the old icon for the exe file in Explorer for a while (icon cache); the window icon changes right away.
