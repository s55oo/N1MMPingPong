## PingPong v1.59

**Overview: function key statistics**
- New tab **Function keys** in `pingpong_overview.exe` on the master PC, and the same table on the web page.
- For every station it shows how many transmissions each key **F1–F12** started, plus **Other** (a caption without an F-key number), **Total** and the total **TX time**. An **All** row adds them up.
- Counts are kept in `pingpong_stats.json` next to the exe, so a restart during the contest loses nothing.
- **Save CSV…** exports the table (`;`-separated, opens in Excel). **Reset…** sets everything to zero, e.g. before the contest starts.
- Only keys that start a transmission are counted, because that is what N1MM reports. Messages sent with Enter (ESM) count under their F-key.

The lamp (`n1mm_lamps.exe`) is unchanged.
