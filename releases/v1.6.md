**PingPong** shows which computer/station on your network is currently **transmitting**. It listens to the N1MM Logger+ external UDP broadcast (XML) on port **12060** and lights up a small always-on-top window in that station's color, showing the caption of the pressed function key.

### Download
- **`n1mm_lamps.exe`** – standalone lamp, no Python required. Double-click to run. Put the optional `lamps.cfg` next to it.

### New in v1.6 – updates and switching back
New **Options ▾** menu in the lamp window:
- **Check for updates** – finds a newer release on GitHub, downloads it, verifies its checksum and restarts the lamp.
- **Switch version…** – install any released version, newer or older.
- **Revert to previous version** – go back to the version you had before the last switch, instantly and without a download, if a new version has a bug.
- **Check for updates at startup** (on by default) and **Install updates automatically** (off by default – you are asked first).

Updates are checked only at startup, so the lamp never restarts while you operate. `lamps.cfg` is kept. Settings are per PC in `pingpong.ini`.

> **Upgrading from v1.5 or older:** download this exe once by hand and replace `n1mm_lamps.exe` on each PC. From v1.6 on, updates come through the Options menu.

See the [README](https://github.com/s55oo/N1MMPingPong/blob/main/README.md#updates-and-switching-back-options-menu-v16) for details.
