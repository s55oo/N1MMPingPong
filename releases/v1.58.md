## PingPong v1.58

**New: PingPong Overview (`pingpong_overview.exe`)**

A separate program for the **master PC**: one live table of every PingPong station.
- **Columns:** station (★ = master), PC, band, mode, frequency, Run/S&P, role, what it is transmitting right now, its last message, F12 and urgent calls, blocked/locked keys, version, last heard.
- **Row colors:** a transmitting row turns the station's color, a station with an F12 call turns yellow, and an urgent call flashes red.
- **Above and below the table:** the master and both F12 block times, a `⚠ TWO MASTERS` warning, version differences, who holds the ping-pong slot, and lamps whose N1MM data doesn't arrive.
- **Web page:** the same table at **`http://<master PC>:8046`**, for any browser on the network, including a phone or tablet. Nothing to install there. Click **Allow web page in firewall…** once so other devices can open it.
- It only listens to the lamps (UDP 46070). It never touches N1MM's port 12060, so it is safe next to the master's lamp.

Download `pingpong_overview.exe` from this release and start it on the master PC.

The lamp (`n1mm_lamps.exe`) itself is unchanged.
