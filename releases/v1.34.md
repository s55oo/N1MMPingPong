### New in v1.34 – My name
**Options ▾ → My name…** gives this PC a short name, e.g. `RUN1` or `RUN2` (max 12 characters).

- The name is shared with all lamps, like the color: every lamp shows `RUN1` instead of the N1MM computer name – in the lamp corner, the line under the lamp and for F12 calls.
- A name already used by another PC is refused.
- Leave it empty to use the N1MM computer name again. Saved per PC in `pingpong.ini`.

Update all PCs – older lamps keep showing the computer name.

### Updating
- **From v1.6 or newer:** start the lamp (or **Options ▾ → Check for updates**).
- **From v1.5:** download `n1mm_lamps.exe` below and replace the old one.
