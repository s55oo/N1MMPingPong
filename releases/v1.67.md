## PingPong v1.67

**Overview: ping-pong lock ON/OFF button**
- New button in the Overview on the master PC: **Ping-pong lock: ON** (green) / **OFF**. One click switches it.
- The master's lamp receives it and passes it on to every lamp at once, the same as the switch in the master lamp's Options. The button always shows what the master currently reports.
- As before, lamps take commands only from the **master PC**, so run the Overview there.

Update all PCs (**Update all lamps…**). The master's lamp must be v1.67 for the button to work.
