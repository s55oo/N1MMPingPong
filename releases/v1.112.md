## v1.112 – date and time in the Diagnostics log header

The line that marks the start and end of logging now has the date and time:
`=== diagnostics ON · 2026-11-15 13:36:55 · PingPong v1.112 · local IPs … ===` (same for OFF), so a session is easy to find in a long `pingpong_test.log`. Nothing else changed.
