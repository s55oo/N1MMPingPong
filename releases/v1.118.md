## CQ WW DX operating status

With the updated N1MM_timer on the master, the lamp shows independent RUN and MULT countdowns in Multi-Single and hourly TX1 and TX2 counts in Multi-Two. Options → Display can also show the time since this PC's last QSO.

The lamp uses the master's time for countdowns. It flags incomplete logs, off-contest bands and ambiguous same-second band changes, and expires stale timer data. Older timer versions continue to supply their existing violation alerts.

The live operating-state sender is included in [N1MM_timer PR #1](https://github.com/s55oo/N1MM_timer/pull/1). The older v0.2.0 and v0.3.0 executables do not send the new status.
