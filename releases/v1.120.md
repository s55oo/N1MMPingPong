## CQ WW lamp status reliability

The master checks the N1MM contest name and number and reports ambiguous database copies. Set `database_folder` under `[contest]` in pingpong.ini to select the intended folder.

Lamps report a missing master radio feed and future-dated contacts. Multi-Single countdowns recover when later band changes establish a definite deadline after a timestamp tie. Enabling the activity display before opening a contest shows the Application Info setup hint.
