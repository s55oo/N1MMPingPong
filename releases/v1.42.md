### New in v1.42 – one master, the same colors everywhere
- **The master follows N1MM:** each lamp reads `IsNetworkMaster` from its own PC's N1MM settings (`Documents\N1MM Logger+\N1MM Logger.ini`). The PC whose N1MM is the network master is PingPong's master too. Switch the master in N1MM's Network Status window – PingPong follows within a few seconds.
- **The master hands out the automatic colors** for all stations; every lamp uses its list, so each station has the **same color on every lamp**. Colors are sticky: they don't change when the master changes.
- If no N1MM reports a master, the lamp started first is master.
- **My color** still always wins.
- The line under the lamp marks the master: `RUN1 7 CW RUN (me, master)`.
- New stations are no longer written to `lamps.cfg` automatically (that per-PC list is what made colors differ). Lines you wrote by hand still work for PCs without a lamp.

Update **all** PCs.

### Updating
- **From v1.6 or newer:** start the lamp (or **Options ▾ → Check for updates**).
- **From v1.5 or older:** download `n1mm_lamps.exe` below and replace the old one once.
