### Change in v1.41 – diagnostics show N1MM's full packets
With **Options ▾ → Diagnostics** on, `pingpong_test.log` now also contains the **full text** of this PC's N1MM packets (`XML: …` lines): AppInfo, contact, score messages and RadioInfo (RadioInfo only when something besides transmit state / key changed; spots are skipped). Used to find out which fields N1MM actually sends – e.g. whether it reports the network master.

### Updating
- **From v1.6 or newer:** start the lamp (or **Options ▾ → Check for updates**).
- **From v1.5 or older:** download `n1mm_lamps.exe` below and replace the old one once.
