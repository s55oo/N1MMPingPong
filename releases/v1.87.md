## PingPong v1.87

**Contest report and operator cheat sheet**

- **Overview → Activity → Contest report…:** after the contest, one page (HTML, opens in the browser – print it or save as PDF from there), saved as `pingpong_report_<date>_<time>.html` next to the exe. It covers the time since the last **Reset** of the statistics:
  - totals: TX time, transmissions, ping-pong waits, F12 and urgent calls, "not heard" alarms;
  - per station: TX time and share, transmissions, busiest hour, waits and time waited, calls, ping, times not heard, alarms, restarts;
  - function keys F1–F12 per station, TX minutes per hour for the whole contest, and the notable events from the event log.
- **Operator cheat sheet:** one page for every operating position – lamp states, keys, ping-pong, what to do about messages. On GitHub as [docs/CHEATSHEET.md](https://github.com/s55oo/N1MMPingPong/blob/main/docs/CHEATSHEET.md) and as a printable PDF ([docs/PingPong-cheat-sheet.pdf](https://github.com/s55oo/N1MMPingPong/blob/main/docs/PingPong-cheat-sheet.pdf)).
