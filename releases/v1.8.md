### New in v1.8 – test mode
**Options ▾ → Test mode – show my button presses** – for testing your N1MM function keys on a single PC.

- The lamp shows this PC's last pressed button even when the radio isn't transmitting and on any band/mode (normally it lights only on a real transmission on 1.8–28 MHz CW/RTTY/USB/LSB).
- Bright for 1.5 s after each new button, then dimmed with the caption still visible. Footer shows `TEST` plus transmit state and band/mode.
- Real transmissions from other stations still take priority. Test mode always starts off.

### Updating
- **From v1.6 or newer:** start the lamp and answer **Yes**, or use **Options ▾ → Check for updates**.
- **From v1.5 or older:** download `n1mm_lamps.exe` below and replace the old one once.
