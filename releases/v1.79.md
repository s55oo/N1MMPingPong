## PingPong v1.79

**Overview: web page firewall state**

- At start the Overview looks for its Windows Firewall rule `PingPong Overview web page` (TCP 8046).
- When the rule exists, the **Allow web page in firewall…** button is hidden and the status line shows `web 0.0.0.0:8046` right after the ping-pong lock state – the web page is reachable from the network.
- Adding the rule with the button hides it a moment later.

Update: the Overview offers **Update Overview to v1.79…** by itself; lamps: **Update all lamps…** (no lamp changes besides the version).
