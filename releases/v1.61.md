## PingPong v1.61

Under the hood. Nothing changes for the operator.

- **Automated tests:** 53 tests run on every push, before anything is built. They cover F12 calls (S&P and Run), urgent calls, the ping-pong lock, the master, commands from the Overview, the keyboard rules, and the Overview's statistics and ready check. If any test fails, no exe is built and no release is made.
- **Thread locking:** the lamp's station and lamp lists are now protected by one lock. The N1MM listener, the lamp-to-lamp messages and the window can no longer see half-updated data. The keyboard hook never waits for it, so key presses are never delayed.
- **Code split:** the lamp is now in clear parts: window, rules, network, common and version. Future changes are safer and faster.
- **Overview updates itself:** when a newer release exists, the Overview asks once and shows a yellow **Update Overview to vX…** button. Statistics and settings are kept.
- **Antivirus:** both exes now carry proper Windows version information. A build that Windows Defender flags is never released.

Lamps from v1.60 on: use **Update all lamps…** in the Overview.
