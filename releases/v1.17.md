### Fix attempt – F-key blocking more reliable
- The keyboard watcher re-installs itself every 10 seconds. Windows silently drops a keyboard watcher that once reacts too slowly, and a watcher installed later by another program sees keys first; both stopped the blocking without any sign.
- Faster key handling (Windows calls prepared once).
- **Test mode** now also logs the keyboard watcher to `pingpong_test.log`: when it is installed, F12 presses ignored because another program was active, incoming calls and when the F-key block switches on and off, and every blocked key.
