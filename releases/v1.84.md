## PingPong v1.84

**Faster Overview, firewall check on the lamp, more tests**

- **Overview uses less CPU:** the Function keys and Activity tables (and the TX chart) are rebuilt at most once a second and only redrawn when something changed – before, they were rebuilt four times a second. The station table and alarms stay as fast as before.
- **Lamp knows its firewall rule:** at start the lamp checks whether its Windows Firewall rules exist. Then **Options ▾** shows **Windows Firewall: PingPong allowed ✔** (click to add them again), and a PC that isn't heard is reported as `check that PC's lamp and firewall` instead of blaming this PC.
- **Windows-only parts tested on every build:** network adapter / ZeroTier detection, one-lamp-per-PC check and the firewall lookup now run as tests on GitHub's Windows runner.
- **Lamp code split** into smaller files (Options menu, updates, phone lamp) – no change in behavior.
