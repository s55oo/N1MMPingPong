## PingPong v1.92

**Network password: set it on the master, the lamps ask for it**

- Set the password **once on the master's lamp** (Options ▾ → **Network password…**). The Overview on the master PC uses it by itself.
- Every other lamp notices that the network is protected and shows a red line: `🔒 this PingPong network has a password – click here to enter it (RUN1)`. Click, type the password once – it is **checked at once** against a message from the master (`Wrong password – try again`) and saved.
- Right after a lamp starts, the question pops up by itself; later only the red line – no window ever jumps in front of N1MM during a QSO. Changing the password on the master works the same way.
- The password never goes over the network; messages are signed, not encrypted.
- Warnings now show station names: `INB2 (10.0.0.5): no network password – ignored`.

Update: **Update all lamps…**, then **Update Overview to v1.92…**. Then set the password on the master's lamp and click the red line on each PC.
