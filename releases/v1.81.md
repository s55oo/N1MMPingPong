## PingPong v1.81

**Phone lamp, alarm when a station goes silent, save/restore setup**

### Phone lamp (every lamp, TCP 8047)
- Every lamp is also a web page: `http://<this PC>:8047`. A phone or tablet shows the same big lamp as the PC (color, message, who sends, frequency, F12 call border) and one tile per band with who is transmitting there. Read only.
- The lamp's top line, left of **Options ▾**, shows where to open it: `phone 192.168.1.20:8047 · ZT 10.147.17.3:8047` – LAN address and, if the PC is on ZeroTier, the ZeroTier address. Click it to open the page.
- **Allow PingPong in Windows Firewall…** now also adds `PingPong phone lamp TCP` (TCP 8047). `--phone-port <n>` changes the port, `0` turns it off.

### Overview: alarm when an operating station is not heard
- A station that has already transmitted and is not heard for **30 s** (PC crashed, lamp closed, cable out): its row turns red, the status line flashes `🔔 NOT HEARD: INB2 45 s`, the Overview beeps every 5 s and the web page flashes.
- **🔔 Silence alarm** stops the beeping; the alarm ends by itself when the station is heard again (also after its lamp restarts). Logged in the event log.

### Overview: Setup ▾ – save and restore
- **Save setup…** writes `pingpong_setup.json`: every PC's name and color (by Windows computer name) and the master's F12 times, ping-pong lock and release time.
- **Restore setup…** (master PC) sends it to all lamps; each lamp takes its own name and color, the master's lamp the master settings. Needs lamps v1.81.

Update: **Update all lamps…**, then **Update Overview to v1.81…** in the Overview. Then, on each PC where a phone should connect: **Options ▾ → Allow PingPong in Windows Firewall…** once.
