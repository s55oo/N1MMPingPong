## PingPong v1.50

**F12 call from Run or from S&P**

Who an F12 call reaches now depends on your mode when you press F12:

| You are in | Called on your band | Call lasts |
|---|---|---|
| **S&P** | only the **S&P** stations (as before) | **S&P call** block time, default **30 s** |
| **Run** | **all** other stations, Run and S&P | **Run call** block time, default **5 s** |

- **Two block times**, both set on the master (1–30 s each): **Options ▾ → F12 block time, S&P call…** and **Options ▾ → F12 block time, Run call…**. They go to all lamps at once; other PCs show them greyed out.
- A Run station's F-keys are blocked by a Run call only if **Block my F-keys…** is ticked on that PC.
- The caller's line shows what kind of call is on: `F12 call ON (14 MHz, Run call – all stations) · 4 s left`.
- S&P stations still can't start a call while another call runs on their band. Run stations can always call.
- The menu item is now called **F12 call – blink stations on my band**.

Update all PCs. An older lamp treats every call as an S&P call.
