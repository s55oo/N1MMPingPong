## PingPong v1.74

**Overview: narrower window**
- The status line has its own row, and wraps if it's long.
- The buttons sit in **two rows** under it:
  - **contest:** Ping-pong lock, Ready check, Test all lamps, Emergency;
  - **maintenance:** Update lamps, Update Overview, firewall, Always on top.
- The Stations table keeps its column widths and **scrolls sideways** when the window is narrow.
- Default window width is now 900 px instead of 1250 px. A size you set yourself is kept.
