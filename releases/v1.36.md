### New in v1.36 – ping-pong lock
For the "ping-pong mode" of multi-op stations: one **RUN** and inband stations (**INB1**, **INB2**) on the same band take turns. PingPong now enforces the turn-taking rule in software, like an interlock box. **Off by default.**

Set the role on each PC under **Options ▾ → Ping-pong role**: **off**, **RUN** or **INB**.

- **RUN** is never locked. Every RUN transmission opens a new period.
- After RUN has transmitted, **the first INB that transmits takes the slot**. Every other INB on that band is **locked until RUN transmits again** (the slot holder may keep transmitting).
- Locked = **F1–F11, Enter and Insert** don't reach N1MM; the lamp shows `WAIT` and `slot taken by INB1 – wait for RUN`. Esc, letters, F12 and Alt combinations always work.
- Only on the same band, only when a RUN is known there, and released by itself after 40 s without a RUN transmission.
- N1MM still prevents two real transmissions at the same time; PingPong adds the alternation.

Details and a step-by-step diagram: [docs/COMMUNICATION.md](https://github.com/s55oo/N1MMPingPong/blob/main/docs/COMMUNICATION.md#5-ping-pong-lock).

### Updating
- **From v1.6 or newer:** start the lamp (or **Options ▾ → Check for updates**). All PCs need v1.36.
- **From v1.5:** download `n1mm_lamps.exe` below and replace the old one.
