## v1.110 – Overview can switch Diagnostics on all lamps

**Settings ▾ → Diagnostics ON on all lamps / Diagnostics OFF on all lamps** in the Overview. Like the other commands it works only from the master PC; every lamp then writes (or stops writing) its own `pingpong_test.log` next to its exe, with the v1.109 `PP` lines. The Overview event log notes that it was sent.

Diagnostics still switches off when a lamp restarts (so a restart or update needs the command again).

Update: Overview → **Update all lamps…**, then restart the Overview.
