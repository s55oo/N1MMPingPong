PingPong – captain's quick chart

master PC + Overview · N1MM Logger+ multi-op · S55OO

1 · Once, every PC

  1. N1MM: Config → Configure Ports… → Broadcast Data → Radio ticked, line 127.0.0.1:12060 127.0.0.1:12062.
  2. Start n1mm_lamps.exe.
  3. Options ▾ → My name… (RUN1, INB1 …).
  4. Options ▾ → Network → Allow PingPong in Windows Firewall…
  5. VPN / ZeroTier adapter set to Private in Windows.

2 · Before the start

  1. Master lamp: Options ▾ → Open PingPong Overview…
  2. Update all lamps… until All lamps v… ✔.
  3. Optional: network password on the master lamp – others click the red 🔒 line.
  4. Ready check → every row green.
  5. Test all lamps – each flashes its own name.
  6. Statistics ▾ → Reset at contest start… (Sat 01:00).

3 · During

  1. Watch the table (colors below) – or the web page on a phone: http://<master>:8046.
  2. Alarm 🔔 NOT HEARD → check that PC → Silence alarm.
  3. PC gone for good → right-click its row → Remove from the list.
  4. Ping-pong lock: ON/OFF for all PCs.
  5. Lamps stuck → Emergency ▾ → restart all (asks twice).

4 · After

  1. Activity tab → Contest report… (opens in the browser – print or save as PDF).
  2. Statistics ▾ → Save CSV… for the raw numbers.
  3. Settings ▾ → Save setup… – names, colors, master settings for next time.

Overview – what the rows mean

✔ READYBefore operating: ready.
problemBefore operating: not ready – reason in Check.
TX CQTransmitting – row in the station's color.
F12 callAn F12 call is on.
URGENTShift/Ctrl+F2/F4 (URGENT / PRIORITY) – flashes.
🔔 not heardOperating station silent 30 s – alarm + beep.
greyNot heard (12 s +) – not operating yet.

★ = master · Ping column: ms to each lamp every 5 min (red = lost or over 500 ms).

Buttons

Row 1Ping-pong lock · Ready check · Test all lamps · Emergency ▾ (restart / stop all)
Row 2Update all lamps… · Settings ▾ (save/restore setup, network password, web page firewall, always on top) · Statistics ▾ (reset now / at contest start, contest report, CSV)
TabsStations · Function keys · Activity (waits, calls, ping, TX per hour, event log)

Keys (operators)

F12Hold-off call: S&P → S&P stations (30 s); Run → all (5 s)
Shift+F2/F4Urgent: sends F2/F4, flashes on the band
Ctrl+F2/F4Priority: others stopped (Esc) and held, then F2/F4

Times and the ping-pong lock are set on the master lamp: Options ▾ → Ping-pong and F12 times.
